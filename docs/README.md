# Documentation

## Purpose

Owns system architecture, durable design decisions, operating procedures, API
references, and safety evidence for BRASH Teleoperation and Interactive
Autonomy.

## Contents

- [Architecture](architecture/README.md)
- [API](api/README.md)
- [Architecture decisions](decisions/README.md)

Operational runbooks, interface references, and commissioning records should be
added only when the corresponding implementation exists.

## Documentation rules

- Mark proposed behavior separately from implemented behavior.
- Keep safety claims tied to measured evidence and a named robot profile.
- Link every externally visible contract to its schema and compatibility policy.
- Supersede accepted decisions with new records rather than rewriting history.
